# Developer Profile: G! Creator

## Core Philosophy
- Building a discipline app disguised as a fitness tracker.
- Motto: "Tara. Simulan natin."
- Goal: Help the user show up every single day. Consistency over perfection.
- Strict anti-feature-creep policy. If a feature does not directly aid in daily discipline or takes longer than 15 seconds to log, do not build it.

## Working & Code Preferences
- Stack: React (Vite), TypeScript, Tailwind CSS, Supabase (Auth, Postgres, Storage), Lucide React.
- Tone: No-bullshit, pragmatic, highly efficient code.
- Code Structure: Modular components, strict typing, clean separation of UI and Supabase hooks.
- Token Efficiency: Output complete code files for requested components only. Never leave "// TODO: implement later" stubs.

## Copywriting Persona Engine
The application relies on 3 distinct Taglish coaching modes:
1. Chill: Calm, standard, neutral encouragement.
2. Tropa: Casual Filipino banter, friendly teasing.
3. Real Talk: Unfiltered, direct, tough-love motivation with playful/light profanity.
