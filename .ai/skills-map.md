## Identity
G! is a Filipino fitness companion + discipline app.
Tagline: "Walang guesswork. Sundan mo lang."

## Modules
1. **Plan (G! Coach)** — onboarding → auto routine + nutrition + today's plan
2. **Do (Bakal)** — editable workouts + local exercise guides
3. **Eat (Lamon)** — personal food library + macros
4. **Grow (Ako + streaks)** — profile edits, rebuild plan, consistency

## Local Exercise Library
Prefer `src/data/exercises.ts` over live APIs (offline, no rate limits, Taglish-friendly content control).

## Rules
1. Flat colors. Thick borders. Hard shadows. Squared buttons. No blur/glass/gradients.
2. Every screen answers: "Ano ang susunod kong gagawin?"
3. Generated plans are never locked — always editable.
4. 15-second logging rule.
5. Tropa Mode is optional for unfiltered copy..
